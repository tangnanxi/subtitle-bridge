字幕桥 0.3.5 — Chrome / Microsoft Edge 网页电影外挂字幕

本版无需注册字幕网站、填写 Token 或配置密钥。只有工具栏弹窗，无需运行网站或服务器。

安装或更新
1. 解压 subtitle-bridge-chrome-edge-v0.3.5.zip。
2. Chrome 打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后的 subtitle-bridge 文件夹，里面应能看到 manifest.json。
5. 已安装旧版时，用新文件替换原文件夹内容，再在扩展管理页点击该扩展的“重新加载”。不要同时启用两份字幕桥。

使用
1. 在网页上开始播放电影，点击工具栏里的“Subtitle Bridge”。
2. 输入电影名或“剧名 S01E01”，选择字幕语言，点击“Find subtitles”。“Include English”勾选框默认开启，会同时查找所选语言和英语，点击 Load subtitles 时自动匹配并加载英文；取消勾选后只查所选语言。
3. 确认“Matched”中的电影名和年份正确。服务每次匹配一部影片，不是同名电影候选列表；如匹配有误，可改用英文片名、年份或 IMDb 编号，例如 tt0133093。
4. 在字幕结果中核对影片版本，点击“Load subtitles”，关闭弹窗后字幕仍跟随视频显示。
5. 字幕早了点“+0.5 s”，晚了点“−0.5 s”。正偏移代表字幕更晚出现。
6. 有多个视频时可在弹窗中选择。已下载的 SRT、VTT、ASS / SSA 文件也可以直接导入。

字幕来源
默认使用 The Subtitle DB 的公开片名匹配与下载接口，不需要账号、Token 或密钥。
https://thesubtitledb.org
接口及集成说明：https://github.com/thesubtitledb/subtitledb-integrations
字幕库的覆盖、中文标签、匹配结果和服务可用性取决于该第三方服务；不保证每部电影都有字幕。没有所选语言的结果时，可换语言、英文名或 IMDb 编号查询。
插件不包含 AI 转写或翻译，不下载、修改电影资源。

兼容范围
- 面向普通 HTTP / HTTPS 网页上的标准 HTML video 播放器，不绑定某个电影网站。
- 跨域嵌入播放器可能要点击“Enable embedded players”，在浏览器提示中授予额外的网站访问权限。
- 部分网站会接管字幕轨道，不能保证所有播放器都兼容。网页刷新、换集或换片源后，请点击“Detect again”并加载字幕。
- 不同剪辑、片头长度或帧率可能造成不同步。目前支持固定偏移，不自动修复随播放时间持续累积的漂移。
- ASS / SSA 只显示对白文本，不保留花字和动画；ZIP、RAR、7z 请先解压再导入。

数据
电影名、集数、所选语言会发送给 The Subtitle DB，以查询相应字幕。不发送电影音频。
字号和字幕语言偏好保存在当前设备，字幕正文只用于当前网页。插件不要求任何登录凭据，旧版保存的 ASSRT Token 不再读取或使用。

验证情况（2026-11-23）
已在隔离 Chrome 中验证真实的免 Token 流程：输入“黑客帝国”，匹配 The Matrix (1999)，下载中文字幕并挂载 1823 条字幕，全程无账号、密钥或 Authorization 请求头。
解析与接口测试 11 项通过；浏览器验证包括导入、搜索挂载、暂停快进同步、时间校准、显示开关、关闭重开弹窗、反复挂载轨道复用、原生视频全屏及同源 iframe。
无头测试浏览器以后台扩展标签页执行同一份弹窗文档；Edge、所有电影网站和跨域 iframe 的权限审批尚未逐项实机验证。

0.3.2 显示修复：普通播放和播放器容器全屏使用独立字幕层，避免自定义播放器关闭或隐藏原生字幕轨道。视频元素原生全屏使用浏览器字幕轨道。已验证字幕实际位于画面内、暂停快进、重叠字幕、显示开关、字号、字幕移除及两种全屏。更新后请刷新电影网页，再重新加载字幕。

0.3.2 英文自动配对：Include English 不再只影响搜索。点击 Load subtitles 后，若所选文件没有已有双语对白，会按发布版本和帧率优先选择英文，并检查字幕时长后一起加载；文件本身已有双语时保持一份。查找或下载英文失败、未找到兼容文件时保留主语言并给出明确提示。Add second / Replace second 保留为手动替换入口。两份文件的 Timing 同时调整；不同剪辑仍可能需要人工选择。实测 Zombieland CROSSBOW 中文字幕一键配上同版本英文，两份文件共 2095 条，合成视频上已确认中英两行实际显示。16 项解析和匹配测试、浏览器自动加载及失败降级测试通过。

0.3.2 重叠修复：普通播放时关闭原生字幕轨道，避免网站与插件重复绘制同一份字幕；更新时清理旧版残留字幕层。视频原生全屏仍使用浏览器字幕。

0.3.3 图标更新：改为蓝色对话框与两条白色字幕线，去掉 CC 字母；字幕功能保持原样。
